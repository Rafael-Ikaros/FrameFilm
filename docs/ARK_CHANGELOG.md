# Ark 更新日志

这里仅记录 `frame_film_ark` 固件与 Flutter Ark App 的联合发布。只有新增加的正式发布节会在推送到 `main` 且两项构建成功后创建 GitHub Release。

- 修复设备文件删除按钮看似正常却无响应的问题：未打开对应设备 app 时，点击删除会说明原因，并提供明确的“显示此文件”操作；显示后再次点击进入原删除确认。只读浏览不切换画面，取消不会删除文件。已通过定向测试与平板提示/确认弹窗验收。

## [2026.10.27.1] - 2026-10-27

App: 0.4.4+8

### 功能与修复

- 修复 App 重连及 WiFi OTA 重启后未自动恢复明日方舟主题的问题：连接成功时直接使用已扫描到的设备广播身份判断主题，不再依赖进入连接页手动刷新设备名称；继续尊重用户关闭主题的选择。
- 修复 WiFi OTA 失败后的恢复流程：重连时自动收尾未完成的传输会话并释放操作状态，使 Film 上传和设置操作可以继续使用。
- 调整 App 面板分组：连接信息与 SD 卡信息合并；固件升级与对应传输状态合并；应用更新与关于信息合并。
- 优化 Ark HTTP 文件直传：接收与落盘采用流水线，复用写入缓冲；配套调整 TCP 接收窗口和接收邮箱。保留进度、取消及失败清理流程，实际速度仍受手机或平板、直连信道和无线环境影响。
- 修复长动画导入与 WiFi 保存问题；已完成 Bad Apple 完整动画的上传及实体播放验收，画面正常并在播放结束后返回菜单。这不代表达到 25 fps 或 30 fps。
- 优化黑白动画 RAM 批量传输，保留已经验证的刷新时序；修复跨应用打开指定图片时先刷新旧图的问题，并补充 BUSY 边沿及刷新阶段耗时诊断。
- 修复查询 App 参数前未载入已保存状态的问题；补充本屏波形、扫描范围与实测结果的技术记录。

验证与当前边界：

- 本次主题修复已通过两项定向 widget 测试，并在当前平板覆盖安装发行签名 APK；WiFi OTA 后停留在设置页即可自动恢复明日方舟主题，重启后的固件构建指纹匹配。
- OTA 失败后重连的 Film 上传与设置操作已通过实机验证。设备已恢复正常固件，显示版本仍为 **3.2.5**，更新识别继续使用构建指纹。
- 独立测速中，约 47.35 MB 文件的纯 HTTP 接收约 **112～148 KB/s**，SD 连续写入约 **2.02 MB/s**，SD 整文件回读校验通过。两轮直连信道不同，不能把速度差异全部归因于参数修改；**尚未实现 1 MB/s**。
- HTTP 内部接收缓冲 16 KiB 等后续候选尚未完成测速验收，相关实验补丁和诊断固件仅保存在本地，未纳入本次提交。
- App 发布版本升级为 **0.4.4+8**，沿用既有发行签名，最低支持 Android 9；已安装正式版可通过应用内检查更新获取。上述实机验收使用同功能代码的本地构建，本次 Release APK 与固件由 CI 重新构建，发布产物本身尚未再次进行覆盖安装与设备升级验收。

### 此前已合入的改进

- Film 与头像编辑增加即时构图预览，连续拖动、缩放及颜色调整不再等待停止操作后才显示；后台合并设备色转换，仅允许导出当前参数对应的结果。修复拖动坐标换算、缩放焦点漂移及预览滚轮带动页面的问题。
- 通行证头像复用 Film 的色彩处理与自适应抖动；黑白模式共享 MonoFast，灰度继续通过黑白半色调表现。应用前保留最近完整预览，并保护取消、重新选择及重试时的异步状态。
- App 主题采用网页同款持久开关：默认开启，仅连接确认的 FRAMEFILMARK 后启用明日方舟主题，断连恢复 ForFilm；保留重看启动界面入口。
- 设备文件浏览改为独立的只读目录查询，不再因点击图片或动画目录而切换设备应用或刷新画面；显式显示及删除前按文件名重新核对实际 ID。
- 连接页展示 SD 总容量、剩余容量及图片/动画数量，并提供对应目录入口。Ark 新增只读协议 0x5B 与 0x59 能力 bit2；此功能需要配套固件，旧固件明确提示升级，未知或部分读取失败不显示为零。

## [2026.10.22.1] - 2026-10-22

App: 0.4.3+7

- 统一设备各页面的中英文字体：英文恢复原版 Unscii 小字与 Montserrat 标题组合；中文小字使用思源黑体 Bold，标题使用对应字号的 Medium。保留现有页面布局、功能、数字字库及品牌图形。
- 同步开机、休眠、主菜单、设置与内容页的字体选择，修复切换语言后公共状态文字未同步更新字体的问题，并补全模拟器页面预览。
- 字体固件已通过网页 BLE OTA 升级，重启后构建指纹匹配；实体中文主菜单及中英文设置页显示清晰完整。发布附件复用这份已经验证的 OTA 应用镜像。
- App 更新源适配仓库改名 Rafael-Ikaros/FrameFilm，并保留 Rafael-ban/FrameFilm 下载地址兼容，修复旧仓库名称校验导致固件和 APK 下载被拒绝的问题。已安装的 0.4.2 或更早正式版需先手动覆盖安装一次 0.4.3，之后继续使用应用内更新；本次沿用既有发行签名。
- 固件设备显示版本仍为 3.2.5，更新判断使用 ELF 构建指纹；本次固件不增加版本号比较条件。

- 修复通行证 WiFi 上传在创建文件前因内部 DMA 内存不足失败（状态 5 / 错误 3）：将 Ark WiFi 静态发送缓冲从 16 个降至 8 个，保留 SDMMC 所需内存，并增加下载阶段 DMA 余量日志。已通过实机复测：BLE OTA 后构建指纹匹配、原有档案保持一致；App 经 WiFi 成功保存 profile.bin（133776 字节）与 profile.json（11370 字节），均为状态 4 / 错误 0，资料回读一致；下载开始时 DMA 最大连续块 13824 字节。

## [2026.10.16.3] - 2026-10-16

App: 0.4.2+6

- App 通行证上传接入 WiFi 直传，统一使用现有临时直连组、进度、取消和清理流程；按顺序保存位图与 JSON，并回读资料，失败后可从头重试上次上传。固件增加 0x5A 指定路径文件接收及 0x59 能力 bit1；旧固件需先升级，网页仍使用 BLE 上传。
- 头像编辑复用 Film 自适应抖动，新导入默认自动选择算法与强度；移除档案画面的头像尺寸标注。
- 修复彩色通行证首次打开或从空状态载入时向上错位、顶部内容被裁切的问题：先切换占位面板可见性并完成布局，再记录彩色卡片坐标。模拟器同步检查实际传给彩色显示层的位置。
- 彩色通行证改用 Film 同款 ColorFast 两阶段彩色快刷，沿用现有六色资料文件；实际色彩及包含切换清屏在内的耗时需实机确认。

- Film 新增实测 ColorQual 原值与 2.5% 校正选项，网页和 Flutter 共享调色板与量化规则；保留原有 ColorQual，通行证继续使用 ColorFast 快刷。
- 已完成相关自动化测试及网页向设备上传校色测试图，实体显示完整、方向正常；实拍仍有灰阶、肤色及浅色偏差，实测校色属于可选试验功能，尚未完成颜色还原验收。
- App 继续使用既有发行签名，版本升级为 0.4.2+6，最低支持 Android 9；固件显示版本保持 3.2.5，更新识别使用构建指纹。
